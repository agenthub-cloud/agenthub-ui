# @agenthub-cloud/ui

AgentHub 聊天 UI 原子组件库：三端（desktop / extension / ruoyi-ui）共用的聊天表面、会话与工作区组件、设计令牌。

> 协议层配套包：`@agenthub-cloud/chat`（本库组件的 props 类型与 engine 来源）。
> 协议语义权威文档在 AgentHub 主仓 `docs/`；消费端接入见本仓 `CONSUMERS.md`（同 chat-sdk 的 GitHub Packages 配置）。
